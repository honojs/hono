# @hono/cloudflare-pages

Cloudflare Pages adapter for [Hono](https://hono.dev).

```sh
npm i @hono/cloudflare-pages
```

## Migrating from `hono/cloudflare-pages`

The exports are the same. Change the import path:

```diff
- import { handle } from 'hono/cloudflare-pages'
+ import { handle } from '@hono/cloudflare-pages'
```

`hono/cloudflare-pages` is deprecated and will be removed in Hono v5.
