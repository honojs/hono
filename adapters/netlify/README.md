# @hono/netlify

Netlify adapter for [Hono](https://hono.dev).

```sh
npm i @hono/netlify
```

## Migrating from `hono/netlify`

The exports are the same. Change the import path:

```diff
- import { handle } from 'hono/netlify'
+ import { handle } from '@hono/netlify'
```

`hono/netlify` is deprecated and will be removed in Hono v5.
